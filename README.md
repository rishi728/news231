# The Daily Brief (static site)

Deploy on Vercel:
1. Go to vercel.com/new and import this folder (upload to a GitHub repo first), or run `npx vercel --prod` inside this folder.
2. Framework preset: Other. Output directory: public. No build command.
3. Open the URL Vercel gives you on your phone.

To publish a new edition, replace public/index.html and redeploy.
